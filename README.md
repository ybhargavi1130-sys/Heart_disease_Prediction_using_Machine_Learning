# ❤️ Heart Disease Prediction using Machine Learning

A Machine Learning project that predicts the likelihood of developing Coronary Heart Disease (CHD) within the next 10 years using the Framingham Heart Study dataset.

---

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. This project applies machine learning techniques to analyze patient health records and predict the risk of heart disease, helping support early diagnosis and preventive healthcare.

---

## 🎯 Objective

- Predict the 10-year risk of Coronary Heart Disease (CHD).
- Perform Exploratory Data Analysis (EDA).
- Preprocess and clean the dataset.
- Train and evaluate classification models.
- Compare model performance using standard evaluation metrics.

---

## 📂 Dataset

**Dataset:** Framingham Heart Study

**Number of Records:** 4,238

**Number of Features:** 16

**Target Variable:** `TenYearCHD`
